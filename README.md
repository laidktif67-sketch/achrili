# AchriLi — اشريلي

منصة تسوّق من المتاجر العالمية إلى الجزائر. المشروع حالياً في بنية **monorepo** تضم تطبيق الويب Next.js وتطبيق الهاتف Expo/React Native وحزم TypeScript مشتركة.

## بنية المشروع

- `apps/web/` — تطبيق الويب باستخدام Next.js وReact.
- `apps/mobile/` — تطبيق الهاتف باستخدام Expo Router وReact Native.
- `packages/api/` — واجهات وخدمات API المشتركة.
- `packages/shared/` — الأنواع والمنطق المشترك.
- `packages/validation/` — قواعد التحقق المشتركة.
- `supabase/` — migrations وEdge Functions؛ لا تُعدّل قاعدة البيانات أو إعدادات المصادقة دون مراجعة مستقلة.
- `tests/` — اختبارات المجال والتكامل الحالية.

## التشغيل

- `npm install` — تثبيت اعتماديات مساحة العمل.
- `npm run dev:web` — تشغيل الويب.
- `npm run dev:mobile` — تشغيل تطبيق الهاتف.
- `npm run build:web` — بناء الويب.
- `npm run typecheck` — فحص TypeScript.
- `npm test` — تشغيل اختبارات Node.js.

## قواعد التطوير

- تطبيق الويب الجديد موجود في `apps/web`، وتطبيق الهاتف في `apps/mobile`.
- لا تُعد إنشاء صفحات HTML مستقلة أو تُدخل Vite مجدداً؛ التطوير يتم داخل مساحات العمل.
- انقل منطق المجال المتبقي تدريجياً من مجلد `src/features/*/model` إلى الحزم المشتركة، ثم حدّث الاختبارات واحذف بقايا التوافق.
- حافظ على ملفات الصور المستخدمة داخل `apps/web/public/assets`.
- لا تضع أسرار Supabase أو مفاتيح `service_role` في الواجهة أو Git.
- لا تنفّذ migrations أو تغييرات إعدادات Supabase كجزء من تنظيف الواجهة.
- اختبر الويب والهاتف قبل اعتماد أي تغيير، ولا تدمج فرع إعادة البناء أو تنشر للإنتاج دون موافقة صريحة.
