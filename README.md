# AchriLi — اشريلي

واجهة عربية RTL لخدمة تسوّق من المتاجر العالمية إلى الجزائر.

## هيكل المشروع

- `index.html`, `auth.html`, `profile.html`, `request.html`, `quotes.html`, `admin.html`, `privacy.html`, `terms.html` — صفحات متعددة مستقلة، مع الحفاظ على HTML الحالي.
- `src/app/` — تهيئة واتفاقيات التطبيق العامة.
- `src/features/<feature>/ui/` — أنماط واجهة كل ميزة.
- `src/features/<feature>/hooks/` — سلوك الصفحة وتنسيق تفاعلاتها.
- `src/features/<feature>/services/` — خدمات خاصة بالميزة عند الحاجة.
- `src/features/<feature>/model/` — قواعد المجال والثوابت.
- `src/shared/services/supabase/client.js` — عميل Supabase مشترك بدل تكرار إنشاء العميل في كل صفحة.
- `src/shared/styles/global.css` — الأنماط العامة.
- `assets/images/` — الصور والرسومات فقط؛ لا توضع ملفات CSS أو JavaScript داخل `assets/`.
- `vite.config.js` و`package.json` — خادم التطوير وبناء الصفحات باستخدام Vite، دون تحويل المشروع إلى React.

## التشغيل

- `npm install`
- `npm run dev` للتطوير المحلي.
- `npm run build` لبناء الإنتاج داخل `dist/`.
- `npm run preview` لمعاينة بناء الإنتاج محلياً.

## الحالة الحالية

واجهة التسوّق ما زالت تجريبية ولا تنشئ طلب شراء فعلياً، لذلك لا توجد حالياً بيانات طلبات أو عناوين محفوظة لعرضها في الملف الشخصي. صفحة الحساب تستخدم Supabase Auth بالبريد وكلمة المرور وتدعم تأكيد البريد واستعادة كلمة المرور. يجب تفعيل مزوّد Google في إعدادات Supabase قبل استخدامه، تسجيل الدخول يتم بالبريد الإلكتروني وكلمة المرور؛ رقم الهاتف الجزائري يُحفظ كبيانات ملف شخصي ولا يُستخدم كمعرّف للدخول. لا تُضمّن مفاتيح service_role أو الأسرار في الواجهة الأمامية.


## عروض الأسعار وإدارة الطلبات

- `quotes.html` تعرض للعميل طلباته وعروض الأسعار التي تسمح سياسات RLS له بقراءتها.
- `admin.html` واجهة أولية للموظفين المخوّلين لإنشاء مسودة عرض وإرسالها عبر وظيفة `admin-quotes`.
- الوظيفة تتحقق من المستخدم عبر Supabase Auth وتطلب `app_metadata.role = admin`; لا تعتمد على `user_metadata` لتحديد المدير.
- يجب نشر الوظيفة وإعداد `SUPABASE_URL`, `SUPABASE_ANON_KEY`, و`SUPABASE_SERVICE_ROLE_KEY` في بيئة Supabase فقط. لا تضف مفتاح الخدمة إلى ملفات الواجهة الأمامية أو Git.
- يجب ضبط أصل CORS المسموح به قبل الإنتاج، وإعداد دور المدير من جهة موثوقة. وظيفة الإرسال تغيّر الحالة إلى `SENT` فقط حاليًا ولا ترسل بريدًا أو إشعارًا.
- حماية منع تكرار العروض الحالية فحص على مستوى التطبيق وليست قيدًا ذريًا في قاعدة البيانات؛ يلزم قيد/معاملة قاعدة بيانات قبل الاعتماد الإنتاجي.
- لا تُعلن سعرًا نهائيًا للعميل إلا بعد التحقق من الشحن والرسوم الإلزامية ذات الصلة.

## ملاحظات التطوير

- حافظ على فصل HTML وCSS وJavaScript.
- استخدم مسارات نسبية للملفات داخل `assets/`.
- اختبر الواجهة على الهاتف وسطح المكتب بعد كل تغيير.
