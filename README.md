# AchriLi — اشريلي

واجهة عربية RTL لخدمة تسوّق من المتاجر العالمية إلى الجزائر.

## هيكل المشروع

- `index.html` — هيكل الصفحة ومحتواها.
- `assets/css/styles.css` — التصميم المتجاوب.
- `assets/js/app.js` — تفاعلات الواجهة والتحقق الأولي من رابط المنتج.
- `auth.html` و`assets/css/auth.css` و`assets/js/auth.js` — واجهة تسجيل الدخول وإنشاء الحساب واستعادة كلمة المرور عبر Supabase Auth.
- `assets/*.svg` — الرسومات والبنرات المستخدمة في الصفحة.

## التشغيل

افتح `index.html` في المتصفح، أو انشر المستودع كصفحة ثابتة عبر GitHub Pages أو استضافة ثابتة أخرى.

## الحالة الحالية

واجهة التسوّق ما زالت تجريبية ولا تنشئ طلب شراء فعلياً. صفحة الحساب تستخدم Supabase Auth بالبريد وكلمة المرور وتدعم استعادة كلمة المرور. يجب تفعيل مزوّد Google في إعدادات Supabase قبل استخدامه، كما أن تسجيل الدخول بالهاتف يتطلب إعداد Phone Auth في المشروع. لا تُضمّن مفاتيح service_role أو الأسرار في الواجهة الأمامية.

## ملاحظات التطوير

- حافظ على فصل HTML وCSS وJavaScript.
- استخدم مسارات نسبية للملفات داخل `assets/`.
- اختبر الواجهة على الهاتف وسطح المكتب بعد كل تغيير.
